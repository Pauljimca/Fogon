# Fogón

Paul's recipe app: recipes in grams, scalable by multiplier, servings, main ingredient or total weight. Installs on iPhone and Android as a web app and works offline. English / Spanish interface.

- Hosted on Netlify, deployed automatically from this repository (no build step).
- Recipes delivered with the app live in `js/seed.js`. Each phone keeps its own copy, its own edits and its own recipes.
